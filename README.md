# shopping-trends-analysis-
"EDA and Visualization of Consumer Shopping Trends using Python &amp; PowerBI"

- **Filename:** shopping_trends.csv  
- **Total Rows:** 390  
- **Total Columns:** 8

### 🧾 Features:
| Column | Description |
|--------|-------------|
| Customer ID | Unique identifier for each shopper |
| Age         | Shopper's age |
| Gender      | Male or Female |
| Item Purchased | Product category bought |
| Category    | Broader product grouping |
| Purchase Amount | Amount spent on the purchase |
| Location    | Shopper's city or region |
| Payment Method | Mode of payment used |

---

## 📌 Project Goals

- Explore purchase patterns across age, gender, and locations  
- Identify most preferred product categories and payment modes  
- Analyze purchase amount trends  
- Build professional-quality dashboards and charts

---

## 🧪 Tech Stack

| Tool / Library | Purpose |
|----------------|---------|
| **Python**     | Data processing & logic |
| **pandas**     | DataFrame manipulation |

| **Git & GitHub** | Version control & publishing |

---

## 📊 Visualizations Created (25+)

- **Bar plots**: Gender-wise purchase frequency for all categorical variables  
- **Histogram + KDE**: Age distribution  
- **Pie charts**: Product category share  
- **Stacked bars**: Payment method by gender  
- **Boxplots**: Purchase amount variation by category  
- **Heatmap**: Correlation between Age and Purchase Amount
